## General Requirements

Set of requiremetns for three vehicles which will be used in C-UAS system.

- Volkswagen Crafter - Wymagania na zabudowę specjalistyczną pojazdu MOBILNE CENTRUM DOWODZENIA.pdf - Points 20 and 21 are talking about IT requrements for the vehicles. The document is in Polish language.
- Volkswagen Amarok - Wymagania na zabudowę specjalistyczną pojazdu NEUTRALIZACJI.pdf - Point 33 is talking about IT requrements for the vehicles. The document is in Polish language.
- Volkswagen Amarok - Wymagania na zabudowę specjalistyczną pojazdu ROZPOZNANIE RADAROWE.pdf - Point 26 is talking about IT requrements for the vehicles. The document is in Polish language.
